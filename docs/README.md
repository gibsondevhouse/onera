## How to use this space

Start with the brand foundation, then develop the visual and verbal identity together. Record settled choices in the decision log and update the relevant guide.

Content marked **Existing** describes the files already in this workspace. **Draft** is an idea we are developing. **To define** is an open question. Existing website treatments and copy are starting material; they do not automatically become final brand standards.

Keep identity guidance here and artwork in the existing `artifacts/` directory. Link to assets from the library so each asset has one source.
